FADLI STORE — STATIC WEBSITE

1. Buka index.html di browser.
2. Edit nomor WhatsApp di js/script.js:
   const WHATSAPP_NUMBER = "6281234567890";
3. Produk dapat ditambah/edit pada array `products` di js/script.js.
4. Keranjang tersimpan otomatis di localStorage.
5. Alur order:
   Produk -> Tambah Keranjang -> Checkout -> Form -> WhatsApp.

Catatan:
- Website menggunakan Google Fonts dan Font Awesome CDN.
- Tidak membutuhkan backend.
